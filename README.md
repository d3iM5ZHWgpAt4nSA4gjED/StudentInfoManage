# StudentInfoManager

StudentInfoManager 是一个用 C 写的 Windows 控制台学生管理系统 可以用来管理学生资料和五科成绩

主界面会显示当前文件、学生人数和保存状态 也能看到每科和总分的最高分、最低分

## 编译方法

### Visual Studio

直接从现有代码创建项目后选择文件夹即可。

### GCC

装好 MinGW-w64 后，在仓库目录打开 PowerShell，运行下面的命令。

```powershell
.\src\build\build-gcc.cmd
```

如果 `gcc.exe` 不在 PATH 里，可以把它的完整路径放在命令后面。生成的程序在 `src\build\StudentInfoManager.exe`。

> 用 Dev-C++ 的话，把 `src` 下的所有 `.c` 文件加到同一个项目里，链接参数加上 `-municode -luser32`。只编译当前打开的 `main.c` 会遇到 `undefined reference to 'openPage'`，因为这个函数写在 `ui/ConsolePage.c` 里。

## 使用方法

### 打开数据

直接打开程序会从空列表开始。想试一下的话，可以点「读取」，选择仓库里的 [testdata.txt](testdata.txt)。也可以把数据文件直接拖到 EXE 上。

启动时也能用 `-file` 指定数据文件。下面用 GCC 编译出的程序举例。

```powershell
.\src\build\StudentInfoManager.exe -file ".\testdata.txt"
```

### 主界面按钮

可以用鼠标点按钮，也可以直接按对应的数字键。功能页里按 `Esc` 或点击底部的「退出」就能回到主界面。

| 快捷键 | 功能 | 用法 |
| --- | --- | --- |
| `1` | 新增 | 依次输入学号、姓名、性别和五科成绩。点表头可以重填，全部填完后自动新增。 |
| `2` | 查找 | 输入学号或姓名的一部分就会实时筛选。留空时显示全部学生，可以用上下方向键或表格内的滚轮翻阅。 |
| `3` | 修改 | 选中学生后点击表头修改对应项目。每项输入后按回车确认，改完再按一次回车提交。 |
| `4` | 删除 | 选中学生后输入 `y` 或 `Y` 并按回车确认。 |
| `5` | 读取 | 输入已有数据文件的路径。 |
| `6` | 保存 | 有当前文件就直接写回，首次保存会要求输入路径。 |
| `7` | 新建 | 输入路径，新建一个空白数据文件。 |

> 新增、修改和删除后记得点「保存」 主界面可以看到还有没有更改没写进文件

## 关于数据文件

第一行是学生总数，后面每行对应一个学生。每条记录是用 Base64 编码的 UTF-8 JSON，解码后的内容长这样。

```json
{"ID":1001,"Name":"张三","Gender":0,"Grade":[90,85,92,88,95]}
```

`ID` 是整数，`Name` 可以填中文，`Gender` 用 `0` 表示男、`1` 表示女，`Grade` 按科目顺序存放五个整数。

Base64 只负责把记录编码成一行文本，拿到文件的人都能解码，请注意数据安全性。

| --- | --- |
| `src/main.c` | 启动、主菜单和退出流程 |
| `src/app/` | 应用状态和提示信息 |
| `src/ui/` | 控制台、主界面、输入框和表格 |
| `src/students/` | 学生结构和增删改查 |
| `src/files/` | 数据文件的读取、新建和保存 |
| `src/lib/` | Base64 和 cJSON |
